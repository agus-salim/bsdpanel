Pasang PHP FreeBSD

PHP 8.2 (php82)

Panel akan menjalankan perintah instalasi paket FreeBSD resmi:

pkg install -y php82 php82-curl php82-mysqli ...
  • Instalasi binary runtime & PHP-FPM daemon
  • Inisialisasi berkas konfigurasi php.ini
  • Modul esensial (cURL, PDO, MySQLi, Zip, GD, Intl, dll)
  • Autostart di /etc/rc.conf

Hapus PHP FreeBSD

PHP 8.2

⚠️ Perhatian Sebelum Menghapus:

Layanan daemon PHP-FPM versi ini akan dihentikan dan paket FreeBSD akan dihapus via pkg delete. Pastikan tidak ada Virtual Host aktif yang masih mengarah ke versi ini.
