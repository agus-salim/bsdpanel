Peralihan Web Server

          
Konflik Port Default 80/443

        

      

      
    


    
    

      

        
        

          Service Apache 2.4 tidak dapat mengikat port 80 karena Nginx saat ini sedang aktif (Running). Silakan tentukan opsi yang Anda inginkan:
        

      


      
      

        

          

            
            
Opsi 1: Beralih Penuh (Rekomendasi)

          

          Port 80/443
        

        

          Otomatis menghentikan Nginx dan langsung mengaktifkan Apache 2.4 sebagai web server utama di server Anda.
        

        
      


      
      

        

          

            
            
Opsi 2: Jalankan Bersamaan

          

          Port 8080
        

        

          Nginx tetap aktif di port 80/443, sedangkan Apache 2.4 akan otomatis dikonfigurasi berjalan di port 8080 sehingga kedua web server aktif bersamaan.
